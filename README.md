# Grok Orbit

Local-first desktop command center for Grok Build CLI, Grok Bot, Grok web, and Cursor.

Local observer plus Orbit-owned ACP, tray summon, MCP fleet tools, FTS search, an activity feed, Bring-to-front, consented grok.com / Cursor web adapters, and cross-tool handoff packs. It does not replace `grok dashboard` inside a pager. It sees the windows that dashboard cannot.

Private. Proprietary. Not orbitstack. GitHub: private `Pitchfork-and-Torch/grok-orbit` only. Do not make public.

## Run

```powershell
cd $env:USERPROFILE\grok-orbit
npm install
npm run tauri dev
```

```powershell
py -3 .\scripts\snapshot.py
```
